# Icônes Papirus

Les fichiers PNG haute résolution de ce dossier proviennent des packs Papirus :

- [Papirus Places](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme) pour les dossiers
- Papirus Mimetypes pour la vidéo
- Papirus Apps pour les paramètres
- Papirus Status pour l’information

Ces ressources sont distribuées sous GPL-3.0 ; l’usage commercial est autorisé. Les PNG 512 px sont réduits par Qt pour conserver un maximum de détails avec le zoom Windows et la Loupe.
